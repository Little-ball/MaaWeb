# MaaWeb 部署指南

本文档说明如何在 Linux 设备上部署 MaaWeb。支持 x86_64 与 arm64（aarch64）。

## 环境要求

- Linux 发行版（Ubuntu 20.04+ 等）
- Rust 工具链（编译服务端）
- Node.js 18+（构建前端，可仅在构建机上需要）
- ADB 可达的 Android 设备（局域网内通过 `adb connect IP:5555` 连接）

## 部署步骤

### 1. 获取 MaaCore 运行时

从 [MAA Releases](https://github.com/MaaAssistantArknights/MaaAssistantArknights/releases) 下载对应架构的 Linux 包：

```bash
# x86_64
wget https://github.com/MaaAssistantArknights/MaaAssistantArknights/releases/download/v6.16.2/MAA-v6.16.2-linux-x86_64.tar.gz

# 或 arm64
wget https://github.com/MaaAssistantArknights/MaaAssistantArknights/releases/download/v6.16.2/MAA-v6.16.2-linux-aarch64.tar.gz

tar xzf MAA-v6.16.2-linux-*.tar.gz -C server/core_runtime/
```

目录结构应为：

```
server/core_runtime/
├── libMaaCore.so          # 核心动态库
├── resource/              # 识别资源
└── ...（其他文件）
```

### 2. 构建服务端

```bash
cd server
cargo build --release
# 产物: target/release/maaweb-server
```

### 3. 构建前端

```bash
cd web
npm install
npm run build
# 产物: web/dist/
```

### 4. 运行

```bash
cd server
./target/release/maaweb-server \
    --core-lib core_runtime/libMaaCore.so \
    --resource-dir core_runtime \
    --web-dir ../web/dist \
    --bind 0.0.0.0:8080
```

> 注意：`--resource-dir` 必须指向**包含 `resource/` 子目录的根目录**（如 `core_runtime`），而不是 `resource/` 本身。MaaCore 的 `AsstLoadResource` 期望传入这个根目录。

启动后浏览器访问 `http://<设备IP>:8080`。

### 5. 配置 ADB 设备

在 Web 界面填写：
- **ADB 路径**：服务器上的 adb 可执行文件路径（如 `/usr/bin/adb`）
- **设备地址**：局域网设备的 ADB 地址，如 `192.168.1.100:5555`

确保设备已开启无线调试（`adb pair` 后 `adb connect` 可达）。

## systemd 服务（可选）

创建 `/etc/systemd/system/maaweb.service`：

```ini
[Unit]
Description=MaaWeb - Arknights Assistant Web UI
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/maaweb
ExecStart=/opt/maaweb/server/target/release/maaweb-server \
    --core-lib /opt/maaweb/server/core_runtime/libMaaCore.so \
    --resource-dir /opt/maaweb/server/core_runtime/resource \
    --web-dir /opt/maaweb/web/dist \
    --bind 0.0.0.0:8080
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now maaweb
```

## 多设备（后续扩展）

当前版本支持单设备。多设备管理在规划中，API 设计已预留多连接扩展空间。
